Verify it yourself

This showcase is a static export. The real proof does not require trusting us:

pip install sia-verifier

sia-verifier attestation.json --chain registry.jsonl \
  --checkpoint checkpoints.jsonl --require-coverage \
  --issuer-key tqIhnSC/3xVANUtzGLsGmcVqxZ40J1jTiF1QDaQHiyw=

sia-rederive

--issuer-key is required. It is the issuer's public key obtained out-of-band (printed above, published in the attestation). The signature must be checked against a key you already trust — not against a key shipped inside the document under test, which would let anyone mint a “valid” forgery with a throwaway key. Without --issuer-key the verifier is fail-closed and never reports VERDICT: VALID.

The chain, checkpoints and flows are in the repository (receipts/, artifacts/, flows/). The verifier checks the Ed25519 signature, the hash chain, signed checkpoints and the Merkle tree — offline, one dependency (cryptography).
